# Notatki – strona

Sama aplikacja Notatki (interfejs i rdzeń w WebAssembly) do otwarcia w przeglądarce. Notatek tu nie ma:
przeglądarka trzyma je u siebie i wymienia przez prywatne repozytorium z notatkami.

Otwierasz ją pełnym adresem z kluczem do notatek po # (zakładka w przeglądarce albo link z narzedzia\opublikuj-strone.ps1 -Link). Nową wersję wysyła narzedzia\opublikuj-strone.ps1.
